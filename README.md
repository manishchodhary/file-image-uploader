# file-image-uploader

A full-stack file and image uploader application built with Node.js, Express, and Multer. Users can upload files/images securely and manage uploads easily.

## Features

- Upload single and multiple files
- Image upload support
- File validation
- Secure backend handling
- Real-time upload status
- Responsive UI
- Organized file storage

## Tech Stack

### Backend
- Node.js
- Express.js
